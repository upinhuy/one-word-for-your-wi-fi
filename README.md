## The word

**Parttime**

Home Wi-Fi behaves like a part-time employee: it shows up when it
feels like it, clocks out right when you need it most, and still
expects full credit for the hours it did work. Full bars, nothing
loading; fine all morning, gone the second the video call starts.

## How it works

`main.ts` (Node 22, standard library only, no network, deterministic)
writes the single word to `/output/entry.txt`:

```sh
node main.ts
cat /output/entry.txt
# Parttime
```

The word is 8 characters, within the competition's 1–20 character gate.

## Why this word

- **True:** every home Wi-Fi drops out at the worst possible moment.
- **Funny at once:** "part-time" needs no explanation — everyone has
  met that employee.
- **Fresh angle:** it does not reach for the usual words about speed
  or buffering; it describes the Wi-Fi's work ethic instead.
- **Works as a network name:** the winning word becomes the sponsor's
  Wi-Fi network name, and `Parttime` reads perfectly as one.
